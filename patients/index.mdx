MedSpace-ში პაციენტის ყველა მასალა — ფაილები, DICOM კვლევები, აუდიო ჩანაწერები და დოკუმენტები — ინახება ერთ საქაღალდეში. ეს განყოფილება განმარტავს საქაღალდეებთან მუშაობის ყველა ფუნქციას.

## საქაღალდის მოქმედებების მენიუ

საქაღალდეზე სამი წერტილის (**...**) დაჭერით იხსნება მოქმედებების მენიუ:

| მოქმედება | აღწერა |
|-----------|--------|
| ფაილის ატვირთვა | PDF, სურათი, აუდიო |
| DICOM ატვირთვა | სამედიცინო კვლევის საქაღალდე |
| აუდიოს ჩაწერა | ხმოვანი ჩანაწერი ბრაუზერიდან |
| შენიშვნა | ტექსტური ჩანაწერის შექმნა |
| გადარქმევა | საქაღალდის სახელის შეცვლა |
| წაშლა | საქაღალდის სრული წაშლა |
